# Requirements

## Python Packages

- `torch>=2.0`
- `transformers>=4.30`
- `accelerate>=0.20`
- `Pillow>=9.0`

## Hardware

- GPU with at least **6 GB VRAM** for inference (FP16).  
- CUDA 11.8 or newer is recommended.

## Environment Variables

- `CUDA_VISIBLE_DEVICES` to select GPU(s).  
- `HF_TOKEN` if accessing private models (not required for this public model).
